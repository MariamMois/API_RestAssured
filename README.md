This project contains API automation tests built using Rest Assured Java.
It follows structured framework design to improve reusability and maintainability.
## Technologies Used
- Java
- Rest Assured
- Maven
- Apache POI 
## Features
- Automated CRUD operations(GET, POST, PUT, DELETE)
- Response validation (status code, body, headers)
- DataDriven using Excel
- Testing reports Using Extend Reports
- Configuration management using properties file
## Project Structures
- endpoints
- payload
- tests
- Utilities
- testData
## Test Runing
- testng.xml
- mvn test
